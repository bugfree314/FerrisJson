- 用户运行 release 版报 `egui_glow: OpenGL: egui_glow requires opengl 2.0+`（环境无 OpenGL 2.0+，典型于远程桌面/虚拟机）。
- 修复：`Cargo.toml` eframe 特性追加 `wgpu`（默认渲染器变为 wgpu，Windows 走 DX12/Vulkan）；`src/main.rs` 新增 `--glow` 参数可强制切回 OpenGL，帮助文本同步。
- `cargo check --all-targets` 与 `cargo build --release` 均通过。Cargo.lock 因新增 wgpu 依赖树而更新。
- 后续修正：eframe 0.33.3 拉取 wgpu 时 `default-features = false`（无任何后端），wgpu 27 后端改为显式 feature，导致 `Instance::new` panic。修复：`Cargo.toml` 直接依赖 `wgpu = "27.0.1"` 并启用 `dx12/vulkan/metal/gles`，`desktop` feature 追加 `dep:wgpu` 做 feature 合并。
