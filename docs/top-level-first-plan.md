### A 的适用限制

后一个顶层键位于前一个值之后，扫描器仍必须读过前一个值才能发现它。因此巨大首值可以先显示其键及类型，但其后兄弟键仍需等待扫描，不能承诺所有顶层键瞬时到齐。

交接前下级展开、检索和完整 JSON 复制/导出不可用；对象或数组预览是占位，标量/字符串仅取有限片段，选中预览最多读取 16 KiB。名称最多保存 640 UTF-8 字节、行标签最多 160 字符；被截断名称不提供不完整的复制路径。单个键的原始编码超过 64 KiB、嵌套超过发现上限 128 或目录超限时停止可选发现，原完整加载仍继续并决定文件是否合法。重复顶层键可暂时按源顺序出现，最终保持原后端既有的最后值语义。

A 保留完整 DOM/完整文件索引及其最终可见行构造，完整加载成本、最终交接卡顿风险尚在。两个阶段并行读取也可能争用 I/O；Low memory load 等待旧文档释放仍可能推迟发现启动。没有把发现预算当作全应用内存保证。粘贴、标准输入、非 Windows 平台和实验分页界面不改为本次默认发现路径。

## B：后台递归与按需展开（0.8.1，人工验收通过）

基于 0.8.0 / `b2d710d`，收录为 0.8.1（本次版本提交）；历史测量版本与哈希保留原值。默认 Windows 文件路径接入，A 的历史实现和测量保留。

1. **会话与节点**：同一受保护源句柄贯穿浏览生命周期，源偏移目录去重、会话内记录身份稳定；重复对象键保持首次位置、最后值，替换值时撤下旧子树。
2. **持续索引与校验**：使用有界深度栈和严格流式词法校验，将各层节点、父子关系、键范围、值范围和子节点目录写入磁盘；不构建完整 AST 或全节点内存数组。值范围已知、子树索引完成、完整文档就绪分别处理；局部扫描只确定边界时仍可触发下级按需索引。
3. **调度**：全局顺序扫描优先减少随机读取；独立交互扫描服务展开容器的首批直接子节点，与全局扫描按源位置合并。最多一个当前交互任务；后台正常扫描仍会遍历深层。后一个字段始终需要跨过前值，交互扫描也可能重复读取未确定边界的巨大值。
4. **原树分页**：64 行可见窗口，磁盘 AVL 保存子节点序号和可见子树权重；展开、折叠、全展开/折叠、选中、路径、Vim 与最多 64 条历史在后台处理。界面消费页面，不执行源文件/目录 I/O；不绘制扫描步骤或进度。
5. **预览与输出**：预览最多 16 KiB、行键最多 160 字符，完整键留在源文件；路径复制后台生成，完整路径上限 8 MiB。完整复制限 8 MiB，超过明确建议导出。完整 JSON 输出等待全局校验就绪，按语义目录处理重复键；流式原子导出使用独立线程，查询/搜索不取消导出，沿用 Cancel export。
6. **功能衔接**：扫描完成仅标记 Ready，不安装旧 Document、不构建旧 expanded/rows 数组。搜索完成后交付磁盘命中，支持高命中及首/中/末跳转；扫描期间检索仍明确要求等待，C 未实现。JSONPath 支持旧文件索引子集与 Pointer、简写路径，兼容结果最多 65,536 条；过滤器/函数明确报错，无整文件回退。CLI、粘贴/标准输入与非 Windows 原路径不变。
7. **验证**：自动测试覆盖提前展开、严格校验、局部扫描领先全局时的重复键、70,000 条高命中及索引缓存驱逐、查询、独立导出/取消、原 UI 无 I/O、快速换文件和资源释放。大文件专项、实际结果见性能记录第 28 节；用户已于 2026-10-15 确认 B 人工验收通过。

### B 的资源与剩余限制

每个活动会话固定 5 条工作线程（顺序校验、交互扫描、页面/导航、查询/搜索/复制、导出）；事件/请求有界且过滤过时代次。临时索引使用固定 8192 条记录缓存，受管理内存配额 64 MiB、临时磁盘配额 64 GiB；配额包含保守预留，不是进程 RSS 保证。

本轮采用逐节点磁盘目录，复用既有磁盘 AVL、校验和及预算机制；尚未对标量数组接入稀疏检查点压缩。临时索引可能大于源文件，高密度节点可能触及磁盘配额；超限明确失败，不退回 DOM。索引不持久化、不提供本会话的缓存恢复。源文件在会话期间不能通过普通写入/重命名方式修改。

全展开/折叠需要后台遍历已发现目录，期间导航可能延后；尚未知晓的兄弟值无法瞬间定位。原 ScrollArea 的极大全局行数仍有浮点滚动精度限制。原生 GPU 呈现、真实磁盘故障与跨平台专项未测。搜索/查询在完整索引前不可用，过滤器/函数和超过兼容上限的 JSONPath 仍待后续实现；这些限制不以有界内存宣称已解决。

### C 的边界

找到后尽快交付不代表无需读过前面的源数据；中部/尾部命中仍受读取、解码和目录写入影响，不承诺任意文件/条件 1 秒命中。字符串字面量按有界块检查；键、数字和正则可能等待范围边界，正则保留每个范围不超过 256 KiB 的限制。暂定命中在重复键替换或非法尾部出现后可撤销，最终计数只在搜索完成后确定。

搜索复用并协助维护 B 的逐节点磁盘目录，密集节点仍有目录写入成本；搜索与全局扫描并行，可能重复读取并争用 I/O。重复键撤销需遍历既有磁盘命中，频繁替换可能增加开销，最终按语义顺序重建也有成本。受管理内存配额继续为 64 MiB、临时磁盘为 64 GiB，不等于 RSS 保证。一般 JSONPath 过滤器/函数、大结果查询分页、标量数组压缩与持久恢复不属于 C。
