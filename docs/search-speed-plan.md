# 检索速度优化工作区

日期：2026-10-16。基线：0.8.9 / `6f3dfcc`。用户授权实施，保持原 UI；用户认可改动并要求提交，收录为 0.8.10（本次版本提交）。

## 实施状态

| 顺序 | 改动 | 状态与边界 |
| --- | --- | --- |
| 1 | 整次搜索复用读取缓冲 | 已实现；Ready 线程复用 Reader，流式 Parser 复用自身读取器，回读恢复位置/行列 |
| 2 | 顺序遍历与短锁 | 已实现；Ready 使用有界中序目录游标，索引期间沿用动态查找；匹配和 I/O 在锁外 |
| 3 | 分块顺序命中 | 已实现；4096 条/块、基础 16 字节/条，直接下标分页；重复键撤回采用稳定整理，最终语义重建保留 |
| 4 | 普通文本/字符串快路径 | 已实现；同块无转义字符串直接匹配，解码窗口复用；普通大小写敏感文本用子串匹配，Unicode 大小写、转义、跨块、数字语义保持 |
| 5 | 有界缓存 | 已实现；同一 Ready 搜索线程最多缓存 1 MiB 最近文件块，包含预算计费与淘汰，不额外缓存完整原文或重复 key 的解码结果 |

缓存只有局部复用收益，不能把 1 MiB 缓存当成完整重复检索加速。结构分配失败时仍可能明确报预算超限；不会回退到磁盘结果或完整 DOM。索引结构本身和匹配总工作量仍受文件节点数、字符串大小、重复键与磁盘影响。
